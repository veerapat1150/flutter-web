แอปพลิเคชั่นวิเคราะห์ธาตุเจ้าเรือนตามหลักแพทย์แผนไทย

## ฟีเจอร์หลัก
- เลือกโหมดผู้ใช้งาน
- กรอกวันเดือนปีเกิดของผู้ใช้
- แสดงโหมดให้เลือก ผู้ใช้ทั่วไปกับผู้เชี่ยวชาญ
- แสดงธาตุหลัก, ธาตุรองของผู้ใช้

## เทคโนโลยีที่ใช้
- Frontend: Flutter
- โครงสร้างฐานข้อมูล JSON
